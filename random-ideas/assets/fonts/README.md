# Locally hosted fonts

Downloaded from Google Fonts on 2026-09-27. These files are served locally; visitors make no requests to Google.

- Shippori Mincho B1: regular (400) and medium (500), Latin and Latin Extended subsets. Used for titles and the site label.
- Noto Sans: variable weights 400–600, Latin and Latin Extended subsets. Used for body copy, controls, and captions.

Both families use SIL Open Font License 1.1. Licences are included alongside the fonts. Do not remove them when distributing the site.

Font declarations and unicode ranges are in `src/theme.css`. Other scripts fall back to the local system fonts.
