# Plush teddy artwork

The current furry atlas and oak box texture are documented in [PROMPTS.md](PROMPTS.md). This file records the original edit source.

Generated with the built-in ImageGen tool as a transparent sprite atlas. The SVG rig composes the atlas through view boxes; facial features remain separate and animatable. The original alpha channel is preserved.
